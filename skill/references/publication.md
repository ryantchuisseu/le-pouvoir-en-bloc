# Fiche de publication YouTube (obligatoire pour CHAQUE vidéo)

Écris `<projet>/publication_youtube.txt` **et** colle son contenu dans le chat, prêt à copier : l'utilisateur publie lui-même et ne doit rien rédiger.

## Gabarit
```
TITRE
<60 caractères max · concept + promesse ou ironie>

DESCRIPTION
<1 phrase courte (15 mots max) : la punchline la plus absurde + 1 emoji>

#shorts #<concept> #expliqué #culturegénérale #<politique|histoire|société>

TAGS (champ « Tags » de YouTube Studio)
<8 à 12 mots-clés : concept, « concept définition », « c'est quoi le concept », synonymes, notions liées, culture générale, politique expliquée, animation>

PARAMÈTRES
Format : Short (vertical, <durée>) · Public · Programmer à 18:00 · Catégorie : Éducation · « Non, ce n'est pas conçu pour les enfants »
```

## Règles
- **Titre** : pas de clickbait mensonger ; une question ou une ironie (« Comment naît une dictature ? Spoiler : démocratiquement »).
- **Description COURTE** : une seule phrase, pas de paragraphe (choix de l'utilisateur).
- **Hashtags** : 5, toujours `#shorts` en premier ; le hashtag du concept sans faute, accents compris.
- **Aucune personne réelle** ni parti nommé ; personnages fictifs seulement.
- Mettre la durée réelle de la vidéo dans PARAMÈTRES.
